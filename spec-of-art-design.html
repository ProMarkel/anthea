PART 02 角色立绘 品质标杆 · 颜色 / 比例 / 五官 / 刻画
2.1 品质标杆 & 特点汇总标杆
参考作品风格标签特点汇总
《七日之都》 休闲都市风 轻魔幻 半厚涂 立绘注重时尚感和现代感，色彩运用低饱和的色彩基调，线条简洁明了；采用半厚涂绘画技巧，使画面更加立体、有层次感
《原神》 休闲都市风 现代治愈 半厚涂 联动中立绘注重时尚感和现代感，色彩运用低饱和基调，线条简洁明了；采用半厚涂技法，画面立体、有层次感
《原神同人》 休闲都市风 半厚涂 线条简洁明了、个性鲜明
📌 选型原则：差异太大，不建议使用，无法匹配风格；存在共性，可以综合使用或分情况使用。
2.2 细节要求细节
🎨 颜色
✓ 推荐低饱和 / 高级灰 / 简洁清新
✓ 可用低饱和 / 色彩清晰明了
✗ 避免高饱和 / 重色彩
📏 比例
  • 立绘基础头身比为 【7-8 头身】，特殊 pose 或体型可适当放宽身体比例
  • 因身高变化产生的头身数变化一般不作为比例标准，通常取男性 175 / 女性 165 的中间值
👁 眼睛
✓ 推荐瞳孔交界线清晰 / 色彩分割清楚
✗ 避免瞳孔色彩分割不清晰 / 眼珠灰蒙蒙
  • 角色的睫毛不要过多
  • 尽量让眼白的分界线清楚明了些
💇 头发
✓ 推荐分组层次分明 / 高光明确 / 边缘变化
✗ 避免高光细碎 / 层次太多
  • 不需要过多细碎的高光
  • 头发明暗关系注意要有体积和结构的表达
👤 面部肤色
✓ 推荐微立体 / 直射光
◐ 视情况平涂 / 弱光影（根据角色性格、性别、年龄适当采用）
✗ 避免强光影 / 油腻
✋ 肢体皮肤
✓ 正确风格平涂 / 微立体
◐ 可选薄涂 / 平面
✗ 避免强光影 / 油腻
🖌 刻画
✓ 推荐平涂 / 明快
✗ 避免细碎 / 繁杂
🖼 各细节要求均配有游戏内展示对照，实际制作请以白皮书内图示为准。
PART 03 角色 Q 版 体型 · 五官 · 勾边刻画
3.1 品质标杆 — 《来我家玩吧》标杆
风格标签：简约清新 卡通可爱
✨ 简约可爱
Q 版人物造型简约，线条简洁，没有过多的细节和修饰，整体呈现出可爱、萌化的特点。
😆 夸张表情
Q 版人物的表情夸张，肢体动作可爱，能够突出角色的个性和特点，增加游戏的趣味性和互动性。
🌈 色彩清新
Q 版人物色彩清馨，对比和谐，能够吸引玩家注意力，同时营造出轻松愉快的氛围。
📌 选型原则：差异太大，不建议使用，无法匹配风格；存在共性，可以综合使用或分情况使用。
3.2 细节要求细节
🧍 体型 & 比例
按男 / 女分别设定体型与比例基准（详见白皮书 Q 版体型比例图示）。
👁 五官 & 头发
✓ 推荐高光随意，或用发丝表现
◐ 可选高光分散，用点表现
✗ 避免高光散、细碎
✗ 避免眼神黯淡
✏️ 细节刻画 — 勾边规范（关键量化指标）
项目规范要求
面部勾边角色面部勾边特殊处理，面部勾边明度在 65 左右，可以用饱和度较高的颜色去勾边
外轮廓勾边框架下粗细为 7~8 像素（常规用 7 像素，结构部分需要加强的用 8 像素）
✓ 推荐勾边均匀 · 过渡自然
✗ 避免勾边不均匀 · 残缺不齐
PART 04 角色动画 拆分细节 · 骨骼与布点
4.1 制作要求 — 拆分细节拆分
📌 选型原则：差异太大，不建议使用，无法匹配风格；存在共性，可以综合使用或分情况使用。
👁 五官的拆分
五官需要单独拆分：眉毛、睫毛、上下眼皮、虹膜、眼白、鼻子、上下唇、上下（齿）、牙、口腔
✋ 手部的拆分
  • 手部动作复杂的情况下需要单独拆分手指
  • 如果有手背 → 手掌侧面的动画，可能需要单独拆分指节
🦴 关节的拆分
关节处建议全部拆分，可以减少蒙皮复杂程度，以减少动画过程中可能的蒙皮非必要拉伸情况
💇 头发的拆分
头发之类的需要多拆几片增加动画的层次感
🩹 遮挡的补全
例如刘海后面要画一个大概的发际线，防止动画可能出现的穿帮；动画中不会露出的部分则不需要
🔍 透明部件的处理
原画中透明的部分，拆分的时候也要拆成透明的
4.2 制作要求 — 动画细节（骨骼 & 布点）动画
🦴 骨骼数量
  • 短发 3-5 根骨骼，长发可以根据短发依比例增加骨骼
  • 发梢末端骨骼数量可以视情况增加（例如发梢弯曲弧度比较大）
  • 作为 Q 版角色，头发和裙子的骨骼数量可以适当减少；腰部的系带、耳环和鼻涕泡骨骼明显过多
✓ 推荐适当的骨骼数量
✗ 避免过多的骨骼数量
📍 顶点布点
  • 使用适当的顶点强调结构，或者表现物体柔软度
  • 过多的布点会影响运行性能，而且动画效果并不会得到提高，反而在后期需要调整时增加工作量
✓ 推荐适当的布点
✗ 避免过多的布点
PART 05 游戏场景 风格 · 布局比例 · 迭代记录
5.1 品质标杆 — 主场景 Q 版匹配标杆
清新整体干净的用色下，会结合一些灰度色过渡带交代场景的虚实远近对比。主场景的色彩应以温暖、柔和的色调为主，如浅绿、浅灰、淡蓝等。色彩搭配应注重层次感和对比度，营造出温馨舒适的氛围。
多元化真实性社交性装饰性
参考：《来我家玩吧》《魔法精品店》— 简约清新 / 卡通可爱
5.2 细节要求 — 风格细节
✗ 建筑结构比例不符合需求结构关系需贴合设定
✗ 刻画方式过于轻薄需保证足够的刻画厚度
✗ 刻画上结构夸张过大需控制夸张幅度
✗ 色调相比偏灰需保持清新明亮
5.3 细节要求 — 布局 & 比例细节
方案效果特征
小比例家具效果 · 更接近写实比例效果，主建筑内可摆放物件数量比大版多
· 游戏前期家具投放数量不多时，建筑内家具摆放后会略显空旷
· 引擎镜头缩小时，场景内容会出现过于密集
大比例家具效果 · 整体效果和比例更有 Q 版效果，整体可爱程度比小版好
· 引擎镜头放至最大时，物件刻画内容更清晰
· 引擎缩小时减少画面密集性
· 游戏前期家具投放数量不多时，整个主建筑不会空旷
· 主建筑内可摆放物件数量比小版少

PART 08 游戏界面 风格 / 颜色 / 字体 / 图标按钮 / 交互
8.1 品质标杆 & 设计风格标杆
🎨 设计风格
  • 色彩搭配以明亮、低饱和色系为主，符合泛女性游戏的特点，同时能够吸引玩家注意力
  • 扁平的材质与简约的形式，营造轻松的视觉感受
  • 游戏图标设计简洁明了，易于识别和理解，方便玩家快速找到所需功能和内容
✨ 风格规范
UI 美术风格以卡通可爱风格为主，注重细节呈现和色彩搭配和谐，同时运用动态元素进行点缀，为玩家提供可爱、温馨的游戏体验。
卡通可爱细节丰富色彩和谐动态元素点缀
8.2 细节要求 — 颜色 & 字体细节
🌈 颜色
  1. 主色调：淡粉色、淡蓝色、淡黄色等温暖色调为主
  2. 辅助色调：根据游戏主题和场景需求，可适当运用其他色彩进行点缀和对比
  3. 色彩搭配原则：遵循和谐统一的原则，避免色彩过于杂乱或冲突
🔤 字体
  1. 字体选择：选用简洁、易读的字体，以提升用户体验
  2. 文字排版：文字排版整齐、清晰，避免拥挤或重叠
  3. 文字颜色：文字颜色与背景颜色形成对比，确保文字可读性
8.3 细节要求 — 图标 & 按钮 / 交互细节
🔘 图标 & 按钮
  1. 图标设计：图标简洁明了，易于识别和理解
  2. 按钮设计：按钮大小适中，位置合理，方便玩家操作
  3. 交互反馈：当玩家点击图标或按钮时，应给出相应的反馈和效果
🖱 交互
  1. 界面布局：界面布局简洁明了，信息展示清晰
  2. 操作流程：操作流程顺畅，符合用户习惯和预期
  3. 交互提示：在关键操作环节提供明确的交互提示，帮助玩家更好地理解和操作
🖼 设计示意
仓库界面 编辑界面 弹窗 小剧场 换装
PART 09 游戏图标 风格 / 构图 / 透视 / 上色 / 输出
9.1 品质标杆 & 风格标准标杆
参考《来我家玩吧》：简洁明了 卡通可爱 色彩鲜明
游戏图标通常以简单的图形和鲜明的色彩为主，能够快速吸引玩家的注意力。同时，图标的设计也与游戏的主题和风格相符合，能够让玩家一眼就能看出游戏的类型和玩法。
9.2 细节要求 — 比例 & 构图细节
典型物件：冰激凌 · 饮品 · 花 · 水果 · 屏风 · 床 · 小摆件 · 落地灯
  • 大家具和小家具可根据需求调整构图中占比的比例
  • 冰激凌和饮品：底部的中心点和透视需一致统一，顶部的瓶口、碗口的透视需一致统一
9.3 细节要求 — 朝向 & 透视细节
项目规范要求
朝向统一统一为 右上打光，高光位置右或右上
透视统一统一升级递进关系
9.4 细节要求 — 上色 & 刻画细节
画法区间：偏平 ⟷ 半厚涂
项目规范要求
投影 & 描边图标绘制以无投影、描边为主。所有描边投影如需添加会提前沟通
图层样式如需添加图层样式，勿在原图层上添加，需复制图层添加；提交版本需保留图层样式，勿合层
边缘处理图标边缘需要处理干净，钢笔勾边，避免有马赛克或边缘模糊的情况
描边 & 渐变描边 10px，细微变化的同色系渐变，上浅下深
9.5 细节要求 — 规范示例示例
  • 勺子、叉子：注意朝向和透视
  • 小装饰：尽可能避免吸管等不必要的过长装饰，会对四个角的信息数字有影响，容易被遮挡
  • 所有同款式类型的物品：要注意大小的统一
9.6 图标输出要求输出
  1. 图像分辨率：保证图像分辨率足够，避免出现模糊或失真现象
  2. 图像质量：图像处理清晰、细腻，符合游戏主题和风格
  3. 图像优化：对图像进行适当的压缩和优化，以降低游戏加载时间和资源消耗
总结END
花语恋的美术品质重点在于色彩运用、空间布局、物品摆放、光线处理、情感表达、创作手法和表现主题等方面。这些细节品质要求在游戏中得到了充分体现和应用，为玩家营造出一个温馨可爱的花神世界。
