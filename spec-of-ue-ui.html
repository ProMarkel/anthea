PART 01 美术表达 设计目标 · 设计灵感
1.1 设计目标目标
  • 延续美术白皮书整体风格：轻松 · 休闲 · 可爱 · 治愈
  • UI 是玩家与游戏交互的第一界面，需保证：风格统一、操作清晰、阅读舒适、节奏明快
  • UI 与场景、角色、特效保持视觉一体感，避免界面抢戏
1.2 设计灵感参考
本章节汇总了主界面、邮件、剧情、小剧场、商店、合成、工坊等核心系统的设计灵感参考，以指导后续 UI 设计的视觉方向：
🌿 主界面 / 庭院
庭院式的场景化布局，柔和的浅绿浅蓝渐变背景。
🎴 邮件 / 列表
手帐风的纸纹底与花瓣装饰，强化叙事氛围。
🎭 剧情 / 小剧场
浮窗式对话气泡 + 角色立绘遮罩，可爱风描边。
🛍 商店 / 交易
货架感的物件陈列，购买按钮高亮强调。
🧪 合成 / 工坊
木制工坊纹理背板，工艺感金属高光。
📜 通行证 / 任务
奖牌式节点路径，节点状态用色阶区分。
📌 完整参考图详见原 PDF P3-P4 美术表达板块（共 2 页）

🔘 外框样式
  • 窗口外按钮：大圆角，整体设计要有立体感设计
  • 窗口内小按钮：要偏向于扁平设计
  • 界面内后续性按钮：要圆角小且几何感设计
🔤 文字显示
✓ 要求文字显示类型按数字奇偶数 2-4 个字
🧩 复杂文字显示
  • 按钮 + 图标 + 按钮外框 + 按钮外信息文本
  • 按钮 + 图标 + 文本（功能类按钮）
2.14 物品信息2.14
📦 基础
  • 图标 + 数字：通常为好感度、金币等功能数值
  • 红点图标 + 副道具图标：图标有附加道具上售卖信息显示
  • 额外功能信息标签：作为顶部额外展示
🧩 复杂物品信息
  • 额外物品信息在最上方拉框显示
  • 额外物品信息样式在文条底部
  • 图样信息显示"999"或数值 + 数字
  • 文本显示2-4 个字

📏 图标尺寸
  • 日常物品图标为标准尺寸

🔄 进度条数值变化

进度条数值变化时，通过图形色彩变化说明数量增加或减少情况：

  • 进度条（增加部分颜色更深） → 数值增加
  • 进度条（减少部分颜色变浅） → 数值减少
🎚 滑动条

  • 用于数值连续调整场景（如购买数量、调节设置）

2.19 命名规范（切图命名）2.19
📐 基础命名规则
命名格式：SCLASS_SResName_Starndard
字段规范
SCLASS资源类型名称，全字母大写。包括目录分类和文件类型。通常在同一文件夹下，有多类型资源的时候使用
SResName资源对象名称，大驼峰式书写格式，字母 + 数字。资源动态匹配时，对应配置标识的本体名
Standard资源规格名称，全字母小写，字母 + 数字。用于区分应用场景，状态等
🏷 类型命名规则
类型说明示例
背景图素材 BG自然感光，作为背景图，一般情况下素材的体积比较大BG_Story_night
框架素材 FRAME可以进行九宫格拉伸的素材。九宫区域大小以基本规范为准FRAME_DiKuang
虚化素材 TILE可以进行四向平铺的素材TILE_HuaWen
按钮素材 BTN自然得光，实际应用为按钮性质的素材BTN_Confirm_small
基础素材 IMG自然得光的非按钮类型素材IMG_WenLi
📎 补充规则
  • 动态图标：涉及到动态图标，单独在图标需求中进行说明
  • 占位图：界面效果图中对应的动态图标，依旧需要提供占位图
  • 例：主界面的动态图标等。属于动态图标，会在图标需求表中单独圆需求。但由于主界面效果画面完成钮，需要允许图。那么在切图的时候也需要附带至少1 个可供关联制作方占位因素
