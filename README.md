# 🌊 海边的安西娅 · Anthea

**Anthea** 是一款温馨治愈的休闲模拟经营游戏，构建于现代都市 × 轻魔幻双层世界观之上。

> 表世界为繁华的现代海滨都市，里世界隐含着创世神话的余韵——在日常经营中，逐步揭开世界背后的秘密。
